# CodeAlpha Internship Projects

This repository contains two projects developed during the **CodeAlpha Internship Program** using Python and NLP concepts.

## Projects Included

### 1. Language Translation Tool
A Python-based application that translates text from one language to another using translation APIs like Google Translate API. Users can enter text, select source and target languages, and view the translated output instantly.

**Features:**
- Multi-language translation
- Simple user interface
- Fast API-based translation
- Copy/Text-to-Speech support (optional)

**Technologies Used:**
Python, Google Translate API, Tkinter/Flask/Streamlit

---

### 2. FAQ Chatbot
An NLP-based chatbot that answers user queries by matching them with the most relevant FAQs using text preprocessing and similarity matching techniques.

**Features:**
- FAQ-based chatbot responses
- NLP text preprocessing
- Cosine similarity matching
- Interactive chat interface

**Technologies Used:**
Python, NLTK, SpaCy, Scikit-learn

- Natural Language Processing (NLP)
